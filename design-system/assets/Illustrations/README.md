# Illustrations

Les quatre planches de référence des offres, en SVG autonome (styles inclus) : `isometria-site.svg` (Site web), `isometria-app.svg` (App métier), `isometria-auto.svg` (Automatisation), `isometria-ia.svg` (IA).

- Fond prévu : `cream-200` `#FEFDF9`. Les fichiers n’ont pas de fond propre.
- Insérez-les en SVG inline pour que les micro-textes prennent IBM Plex Sans, Nunito Sans et JetBrains Mono. En `<img>`, ils retombent sur les polices système.
- Ne recolorez pas une planche et n’ajoutez pas de seconde pièce sauge. Règles : section « Illustrations ».
