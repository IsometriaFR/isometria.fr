# QuoteStats

Quote & stats — blockquote and stat numbers.

- **IBM Plex Sans** — H1 / H2 / H3, blockquotes, stat numbers.
- **Numbers.** One to nine spelled out in prose; 10+ as digits. Stats, prices, units, dates, years: always digits. Percentages: digit + NBSP + `%`.
- **Non-breaking spaces** before `;`, `:`, `?`, `!`, `%` and between value + unit (`7 ans`, `100 %`).

The preview draws these with its own styles: `components/bundle.js` exports no component for them.
