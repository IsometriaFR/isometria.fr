# Badges

Info / neutral pills + mono tech tags.

- **Casing.** Sentence case everywhere. Only exception: micro-labels (badges, uppercase tags) with `letter-spacing: 0.08em` to compensate.
- **Radii.** `4px` for tight tokens (inline code, tech tags), `999px` (pill) for badge chips.
- **JetBrains Mono Variable** — code inline, code blocks, version tags, file paths.
- System states (success olive, warning amber, danger red) are utility-only — never used in editorial copy.

The preview draws these with its own styles: `components/bundle.js` exports no component for them.
